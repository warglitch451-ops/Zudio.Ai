What this prototype does

  • Generate a single-page website as HTML using a configured Gemini API.
  • Load a built-in sample to test preview, editing and downloads without an API key.
  • Edit HTML manually, refresh the preview, save projects locally and download HTML.
  • Saved projects remain in this browser only; they are not synced between devices.

Not included yet

  • Real Shopify OAuth, store publishing, checkout or payment processing.
  • Cloud accounts, team collaboration, database, hosting or custom-domain deployment.
  • Secure server-side API key management or production monitoring.
This is a functional front-end prototype, not a finished hosted SaaS product. Test all generated output before using it for a client.
