Security

Enter a model ID that is actually available to your Gemini API project. Model availability and naming can change. This app does not assume that an unverified name such as “Flash 3.8” exists.

Prototype security: API requests are sent from this browser and the key is not stored by this page after reload. This is not safe for a public commercial deployment. In production, keep the key in server-side environment variables, authenticate users, add usage limits and log costs without exposing secrets.

Suggested production controls: provider health checks, per-client quotas, request timeouts, retries, audit logs, key rotation and role-based access.
